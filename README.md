# Embedding Search Viewer

PC の中にある **画像・PDF・動画** を、**言葉や画像で探せる** Windows アプリです。

「赤いスポーツカー」「グラフのあるスライド」「海辺の夕焼け」のように、ファイル名を知らなくても、**見た目や内容**で探せます。

- 🔒 **すべて自分の PC の中で処理します**。画像や文書が、外部に送られることはありません（通信するのは、最初の AI モデルのダウンロードだけです）。
- 🖼️ **画像で探す**こともできます。手元の画像と、似た画像を探します。
- ⚡ **GPU があると、とても速く**インデックスを作れます（目安: 画像 1,000 枚で、約 2〜3 分）。

## ダウンロード

最新版は、[Releases ページ](https://github.com/SoraKumo001/embedding-search-viewer/releases/latest) にあります。次のどちらかを選んでください。

**インストーラー（おすすめ）**: `EmbeddingSearchViewer-<バージョン>-win-x64-setup.exe`
1. ダウンロードして、実行します（管理者権限は不要です。`%LOCALAPPDATA%\Programs` に、インストールされます）。
2. スタートメニューの「EmbeddingSearchViewer」から、起動します。
3. アンインストールは、「設定」→「アプリ」から行います（インデックスや AI モデルも消すかどうか、聞かれます。「いいえ」なら、残ります）。

**zip（インストールしたくないとき）**: `EmbeddingSearchViewer-<バージョン>-win-x64.zip`
1. ダウンロードして、好きな場所に展開します（例: `C:\Apps\EmbeddingSearchViewer`）。
2. 展開したフォルダの一番上にある、**`EmbeddingSearchViewer.cmd`**（種類: Windows コマンド スクリプト）を、ダブルクリックして起動します。アプリ本体のファイル（約 400 個）は、`app` フォルダの中にまとめてあります。

**初回に表示されることがあるもの**
- 「Windows によって PC が保護されました」（SmartScreen）: このアプリには、まだコードの署名がないため、表示されることがあります。次のどちらかで、起動できます。
  - **起動するとき**: 画面の「**詳細情報**」をクリックすると、「**実行**」ボタンが出るので、それを押します。
  - **警告を出さない（おすすめ）**: zip を**展開する前に**、ブロックを解除します。zip を右クリックして「プロパティ」を開き、「**許可する**」にチェックを入れて「OK」を押します。PowerShell なら、次のとおりです。

    ```powershell
    Unblock-File .\EmbeddingSearchViewer-0.1.0-win-x64.zip
    ```

    すでに展開した場合は、フォルダごと解除します。

    ```powershell
    Get-ChildItem -Recurse C:\Apps\EmbeddingSearchViewer | Unblock-File
    ```

  心配な場合は、次のとおり、ダウンロードしたファイルが、公開されたものと同じことを確認できます。

```powershell
(Get-FileHash .\EmbeddingSearchViewer-0.1.0-win-x64.zip -Algorithm SHA256).Hash.ToLower()
```

表示された値が、Releases ページの `SHA256SUMS.txt` に書かれた値と同じなら、問題ありません。

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 11（検証した環境）。Windows 10（1809 以降）でも動く設計ですが、検証は Windows 11 で行っています |
| CPU | 64 ビット（x64）。ARM 版の Windows には、対応していません |
| GPU | **DirectML に対応した GPU を推奨**（NVIDIA / AMD / Intel など。開発・計測は NVIDIA GeForce RTX 4070 Ti）。GPU がなくても動きますが、インデックスの作成が、**大幅に遅くなります**（目安: 画像 1 枚あたり、数秒） |
| ディスク | 約 2.5 GB（アプリ 約 0.5 GB、AI モデル 約 1.8 GB） |

## はじめかた

### 1. AI モデルの準備（初回だけ）

初回の起動では、「**モデル**」画面が開きます。「**ダウンロードを開始**」をクリックしてください。

- ダウンロードの大きさは、約 1.8 GB です。通信の状況によって、数分〜数十分かかります。
- **途中で中断しても、続きから再開できます**。アプリを閉じても、次回、続きから始まります。
- ダウンロードしたファイルは、公開されているチェックサムで、自動的に検証されます。

### 2. 探したいフォルダを登録する

1. 左のメニューから「**ライブラリ管理**」を開きます。
2. 「**フォルダを追加**」をクリックして、画像・PDF・動画があるフォルダを選びます（フォルダを、画面にドラッグ&ドロップしても追加できます）。
3. 「**インデックス作成を開始**」をクリックします。

インデックスの作成が終わるまで、少し待ちます。2 回目からは、**新しいファイルや、変更されたファイルだけ**が処理されるので、すぐに終わります。

| 対象 | 処理される内容 |
|---|---|
| 画像（JPEG / PNG / WebP / BMP） | 画像の内容。スマートフォンの写真の向きも反映されます |
| PDF | ページごとの見た目と、ページの文字 |
| 動画（mp4 / mkv / webm / wmv / avi / mov / flv） | 15 秒ごとの場面（「ライブラリ管理」で、30・60・120 秒にも変えられます） |

**動画の取り込みには、時間がかかります。** 目安は、1 時間の動画で、約 3〜5 分（場面が 300 場面前後、複数の動画は、同時に処理されます）。数時間の映画では、1 本あたり 10 分以上かかります。
- 処理中は、動画ごとに、「**場面 420 / 1,050**」のように、進み具合が表示されます。
- **途中で「中断」しても、アプリを閉じても、続きから再開します**（終わった場面は、やり直しません）。
- 長い動画が多いときは、「**動画の場面の間隔**」を長くすると、速くなります（検索できる場面は、粗くなります。変更は、これから取り込む動画に適用されます）。

### 3. 探す

1. 左のメニューから「**検索 & ビューア**」を開きます。
2. 上の検索ボックスに、探したいものを書いて、Enter を押します。
   - 例: `赤い車` / `グラフのあるスライド` / `a dog running on the beach`
3. 左に、結果が一覧で表示されます。クリックすると、右にプレビューが表示されます。

## 使い方

### 画像で探す

手元の画像と似た画像を探せます。次のどれでも構いません。

- 検索ボックスの横の「**画像で検索**」から、画像を選ぶ。
- 画像を、ウィンドウに**ドラッグ&ドロップ**する。
- 結果の画像を**右クリック**して、「この画像に似たものを検索」を選ぶ。

### 絞り込みと並べ替え

検索ボックスの下で、次のことができます。

- **キーワード検索を併用**: ファイル名や、PDF の文字も使って探します。
- **最小類似度**: 小さくすると、広く拾います。大きくすると、近いものだけになります。
- **並べ替え**: 関連度 / 類似度 / ファイル名。
- **詳細フィルタ**: 更新日、サイズ、フォルダ（パスの一部）で絞り込みます。
- 時計のアイコンから、**検索の履歴**を呼び出せます。

### プレビュー

| 操作 | 動作 |
|---|---|
| マウスホイール | 拡大・縮小 |
| ドラッグ | 拡大中に、画像を動かす |
| ダブルクリック | 拡大と、全体表示の切り替え |
| 「外部アプリで開く」 | 普段使っているアプリで開く |

動画は、**一致した場面から**再生できます。

### 動画の結果は、動画ごとにまとまります

動画は、場面ごとに探しているので、長い動画 1 本で、結果が埋まってしまうことがあります。そこで、**同じ動画の場面は、1 件にまとめて表示**します（いちばん一致した場面が、代表になります）。「**一致した場面 12 件**」のように、件数も出ます。

動画の結果を選ぶと、**プレビューの下に、一致した場面の一覧**が出ます。
- 場面をクリックすると、その場面から再生します。
- 並べ替えは、「一致順」と「動画の時間順」から選べます。
- 一覧の上のボックスで、**その動画の中だけを、別の言葉で探せます**（例: 動画を「海」で見つけて、その中で「花火」を探す）。空にして「動画内を検索」するか、「一致した場面に戻す」を押すと、最初の検索の一覧に戻ります。

まとめたくないときは、検索オプションの「**動画を 1 件にまとめる**」を、オフにしてください（場面ごとに、1 件ずつ表示します）。

### 結果の右クリックメニュー

外部アプリで開く / フォルダを開く / パスをコピー / この画像に似たものを検索

### 同じ画像が、何枚もあるとき

内容がまったく同じ画像は、結果に 1 件だけ表示され、「**同一画像 他 N 件**」と添えられます。真っ白（ほぼ一色）のページは、インデックスに入りません。

### フォルダの変更を、自動で反映する

「ライブラリ管理」の「**フォルダを監視して自動でインデックスを更新**」をオンにすると、ファイルの追加・変更・削除が、自動で反映されます（初期状態はオフです）。

### ライブラリの整理

「ライブラリ管理」の、次のボタンを使えます。

- **更新**: 統計を再読み込みします。
- **削除済みを除去**: 元のファイルがなくなったものを、インデックスから外します。
- **白紙を除去**: ほぼ一色の画像を、インデックスから外します。
- **クリア**: インデックスをすべて消します（元のファイルは、消えません）。

**読めない画像は、次回から、対象から外れます。** 画像の読み込みに、何度か失敗したファイルは、壊れている可能性が高いので、次回のインデックス作成から、自動で、対象から外します（毎回、同じファイルを試して、時間を使わないためです）。外したファイルは、「ライブラリ管理」の「**インデックスから外したファイル**」に、理由と一緒に出ます。
- ファイルを直したり、置き換えたりして、サイズや更新日時が変わると、**自動で、対象に戻ります**。
- 一時的な失敗だったときは、「**対象に戻す**」（1 件ずつ）、または「**すべて対象に戻す**」を押すと、次回のインデックス作成で、もう一度、試します。

### 仕事用・趣味用など、探す対象を切り替える（プロファイル）

画面の上の「**プロファイル**」で、探す対象を切り替えられます。プロファイルごとに、**登録したフォルダ、インデックス、検索の履歴**が別々です。仕事の資料と、趣味の写真を、混ぜずに探せます。

- **切り替える**: 「プロファイル」の一覧から選びます。検索の結果と入力中の内容は、切り替えるとクリアされます。
- **追加する**: 横の「…」→「新しいプロファイル...」で、名前（例: 仕事、趣味）を付けて作ります。作ると、そのプロファイルに切り替わります。空の状態なので、「ライブラリ管理」でフォルダを登録して、インデックスを作ってください。
- **名前を変える**: 「…」→「名前を変更...」（いま選んでいるプロファイルの名前が変わります）。
- **削除する**: 「…」→「削除...」。選んだプロファイルの、インデックス、キャッシュ、フォルダの設定、検索の履歴が消えます。**元の画像・PDF・動画は消えません**。使用中のプロファイルは、削除できません。
- **インデックス作成中は、切り替えられません**。完了するか、中断してから切り替えてください。

はじめは、「**標準**」というプロファイルが 1 つあります。以前のバージョンで作ったインデックスは、ここに引き継がれます。AI モデルは、すべてのプロファイルで共通です。

### ウィンドウの大きさと位置

アプリを終了するときの、**ウィンドウの大きさと位置（最大化も）を覚えて**、次の起動で、同じ状態に戻します。

- 前回の位置が、いまの画面では見えない場合（モニターを外した、解像度を変えた、など）や、保存された値が、おかしい場合は、**標準の大きさ（1280 × 840）**で、Windows が決めた位置に開きます。
- 標準に戻したいときは、アプリを閉じて、`%LOCALAPPDATA%\EmbeddingSearchViewer\window.json` を削除してください。

## データの保存場所とプライバシー

- 画像・PDF・動画の内容を、**外部に送ることはありません**。AI の処理は、すべてこの PC の中で行います。
- 通信するのは、**初回の AI モデルのダウンロード**だけです（Hugging Face から取得します）。
- アプリが作るデータは、すべて次のフォルダにあります。

```
%LOCALAPPDATA%\EmbeddingSearchViewer\
```

| 中身 | 内容 |
|---|---|
| `models\` | AI モデル（すべてのプロファイルで共通） |
| `profiles.json` | プロファイルの一覧と、最後に使ったプロファイル |
| `window.json` | ウィンドウの大きさと位置（すべてのプロファイルで共通） |
| `profiles\<プロファイルの ID>\media_index.db` | 検索用のインデックス |
| `profiles\<プロファイルの ID>\library.json` | 登録したフォルダなどの設定 |
| `profiles\<プロファイルの ID>\search_history.json` | 検索の履歴 |
| `profiles\<プロファイルの ID>\excluded_files.json` | 読めずに、インデックスの対象から外したファイル |
| `profiles\<プロファイルの ID>\cache\` | PDF のページ画像、動画のサムネイル |

**アンインストール**: アプリのフォルダと、上のフォルダを削除してください。元の画像・PDF・動画には、一切触れません。

## 困ったときは

**モデルのダウンロードが止まった・失敗した**
同じ画面で、「ダウンロードを再開」（または「再試行」）をクリックしてください。続きから再開します。ディスクの空き容量が足りないときは、メッセージが表示されます。

**検索しても何も出ない**
「ライブラリ管理」で、フォルダを登録して、「インデックス作成を開始」を実行したか確認してください。まだ、インデックスが空の可能性があります。

**「別の埋め込みモデルで作成されています」と表示された**
インデックスを作ったときと、今のモデルが違います。「ライブラリ管理」の「**クリア**」をしてから、「インデックス作成を開始」で作り直してください。

**画像・PDF・動画が、検索に出てこない**
- 対応する形式か、確認してください（上の表）。
- 内容がほぼ一色の画像（白紙など）は、わざと除外しています。
- パスワード付きの PDF は、ファイル名でしか探せません。
- 動画は、コーデックによっては、中身を読めないことがあります（その場合は、ファイル名で探せます）。

**インデックスの作成が遅い**
GPU がない（または使えない）と、画像 1 枚あたり数秒かかります。DirectML に対応した GPU のある PC を、お勧めします。

**「既存のインデックスを新しい保存場所へ移動できませんでした」と表示されて起動しない**
古いバージョンのアプリが、まだ起動したままです（バージョンを上げて、初めて起動したときだけ起こります）。すべてのウィンドウを閉じて（タスクマネージャーで、`EmbeddingSearchViewer.App` が残っていないことを確認して）、もう一度起動してください。インデックスは、移動されないまま残っているので、消えません。

**アプリが起動しない**
- ダウンロードした zip は、**展開してから**起動してください（zip の中から直接は動きません）。
- 展開したフォルダごと移動した場合は、そのフォルダの `EmbeddingSearchViewer.cmd`、または、`app` フォルダの `EmbeddingSearchViewer.App.exe` を、起動してください。
- `EmbeddingSearchViewer.cmd` を実行したときに、一瞬、黒い画面が出るのは、正常です（アプリを起動して、すぐに閉じます）。

## 対応していないこと

- GIF / HEIC / AVIF などの画像形式。
- zip / cbz などのアーカイブの中身。
- ARM 版の Windows。
- 音声の検索。
